# 《十善業道經》互動電子書——設計

日期：2026-11-18。使用者核可的方向：「翻頁式互動電子書」（對話中回覆「好」，並選擇直接開工、做到上線＋部落格草稿再審）。

## 為什麼做

omilkyway.org 的「經典互動」主題：把經典做成手機打開就能讀、能玩的網頁，再搭配一篇主題文章。已有弟子規小遊戲與三款遊記遊戲。《十善業道經》和弟子規同屬淨空法師說的「三個根」（儒：弟子規／道：太上感應篇／佛：十善業道經）。

## 目標

- 讀者能把整部經從頭讀到尾：原文一字不漏、每段有白話、難詞有註解、可以朗讀。
- 互動都取自經文本身，不另編劇情：
  1. **功德寶珠**：十善各自的功德（10、10、4、8、5、8、3、5、8、10，共 71 條）一條一顆，點一下看白話並點亮。
  2. **生活情境題**：十善各一題現代生活的抉擇，三個選項，選完給溫和的回饋，不計分。
  3. **十善配對**：十善 ↔ 所得功德的名目（離殺生→十離惱法…）。
  4. **十善大地**：一張「十善大地」的圖分成 2×5 共十方，每圓滿一善（該章寶珠全亮）就散開一方雲霧。
  5. **每日十善**：對應經文「晝夜常念思惟觀察善法」，每天十項自我檢核，紀錄只存在瀏覽器。
- 手機直式優先（480px 欄寬），寬螢幕左圖右文；可用 iframe 嵌進部落格。

## 不做

- 不編故事、不設角色扮演、不打分數、不排名。
- 不做帳號、不上傳任何資料、不放廣告。
- 這一版不做分享卡、QR。GA 原本不做，2026-11-19 使用者要求後加上（自己一個 GA 帳戶「Ten Virtues Sutra」，比照三款遊戲各自一個帳戶）。

## 絕對不能出現（做出來也算失敗）

- 經文被改字、漏字、錯字。以 CBETA 現行版為準（`tests/fixtures/T0600-cbeta.txt`，測試逐字比對）。
- 白話轉載別人的譯文。白話、註解、情境題全部自己寫。
- 嚇人的報應描寫、對其他信仰的貶抑、健康療效的宣稱。功德一律以「經文說」的口吻呈現。
- 情境題出現說教、羞辱選錯的人。

## 內容規則

- 對象：國高中以上到大人，親子可共讀。用語是台灣的白話，一句話講得完就不用兩句。
- 經文底本：CBETA 2026.R2（T15 No.600，唐・實叉難陀譯）。大正藏原作「正莊嚴故」，CBETA 依宮本等校訂為「止莊嚴故」，本書從 CBETA，並在該條加校勘說明。
- 授權：CBETA 資料庫為 CC BY-NC-SA 4.0、限非營利，再加工需附其使用說明與版本資訊 → 做在「關於本書」頁。

## 技術（與三款遊記相同的做法）

- 純靜態網頁，無建置步驟：原生 ES modules＋JSON 資料＋一個 CSS 檔。GitHub Pages 根目錄發布。
- 路由用 hash（`#/`、`#/toc`、`#/ch/3`、`#/match`、`#/land`、`#/daily`、`#/about`），瀏覽器返回鍵可用、可深連結。
- 存檔：`localStorage`，`shishanBook.v1`（進度）、`shishanDaily.v1`（每日十善）。localStorage 不可用時整本書仍可閱讀，只是不保存。
- 朗讀：瀏覽器內建 `speechSynthesis`，逐句排隊；沒有中文語音或不支援時隱藏朗讀鈕。
- 測試：vitest＋happy-dom。
- 插圖：draw 技能（gpt-image-2、low、1536×1024）→ `art-src/` → `npm run opt-art` → `assets/art/*.webp`。畫風沿用遊記系列的廟宇彩繪 Q 版，改海底龍宮的青綠色調；畫中不得有字。

## 資料形狀

`js/data/chapters.json`：陣列，每章

```json
{
  "id": "ch03", "no": 3, "kind": "virtue",
  "title": "離殺生", "subtitle": "不傷害生命",
  "art": "v01-no-killing.webp", "alt": "……",
  "virtue": { "index": 1, "group": "身", "short": "不殺生" },
  "blocks": [
    { "type": "passage", "raw": "原文（含標點，與底本逐字相同）", "plain": "白話", "terms": ["詞條鍵"] },
    { "type": "list", "role": "benefits", "name": "十離惱法", "nameNote": "十種遠離煩惱的好處",
      "items": [ { "raw": "一、於諸眾生普施無畏；", "plain": "白話", "terms": [] } ] }
  ],
  "scenario": { "prompt": "……", "options": [ { "text": "……", "reply": "……" } ] },
  "takeaway": "一句帶走的話"
}
```

- 所有 `raw` 依序串接、去掉空白後，必須等於底本去掉空白的全文。
- `role: "benefits"` 的清單項目才算寶珠（共 71）；`role: "plain-list"`（第 13、14 章）只是可展開白話的清單。
- `js/data/glossary.json`：`{ "鍵": { "term": "出現在原文裡的字串", "note": "註解" } }`；區塊用 `terms` 引用，引用的 term 必須出現在該區塊的 raw 裡。
- `js/data/daily.json`：十項每日檢核文字。

## 追加：點圖放大（2026-11-18 使用者提出）

使用者看過上線版後要求：「圖片也可以點了就放大嗎？天堂遊記也是這樣。」行為比照《天堂遊記》／《地獄遊記》已定案的做法：

- 封面與各章插圖點一下，全螢幕顯示完整的圖（`object-fit: contain`，版面上的是裁切過的），淡入；純檢視，不做雙指縮放。
- 關閉：點任意處、右上 ✕、Esc、手機返回鍵。開啟時鎖住背景捲動，關閉後還原。
- 歷程管理直接移植遊記的 `js/ui/layer.js`（全域只持有一筆 history 紀錄、microtask 對帳）。這本書另外用 hash 做路由：疊層推的紀錄不改網址，不會觸發 hashchange；大圖開著時停用左右鍵翻頁。
- 和遊記不同的地方：這本書的圖有 alt 文字，所以圖包在 `<button>` 裡，鍵盤也開得了；開啟時焦點移到 ✕，關閉後回到原圖。圖的右下角有一個小放大鏡提示。
- 「我的十善大地」還有雲霧時不能放大（放大就看光了），十方都散開之後才可以。
- 凡是動到 `layer.js`，一定要在真的瀏覽器裡重驗：開圖後按返回鍵只關大圖、不換頁；連開連關幾次後按一次返回就回到上一頁；在歷程第一頁開圖按返回不會離開這本書。
